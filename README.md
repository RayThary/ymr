# Dimension Warrior

Unity 기반 런앤건 / 로그라이트 협업 프로젝트입니다.

## 프로젝트 개요
- 장르: 런앤건 / 로그라이트
- 개발 엔진: Unity 2022.3.4f1
- 개발 기간: 약 3달
- 개발 형태: 협업 프로젝트
- 목표: 여러 차원의 보스를 처치하고 원래 차원으로 돌아가는 보스전 중심 게임 구현

## 주요 구현
- 보스 타입별 패턴 구현
- 플레이어 위치 기반 공격 패턴
- 체력 조건에 따른 보스 패턴 변화
- 땅 오브젝트 기반 패턴 구현
- 사운드 매니저 및 SFX 풀링 구조

## 기술 포인트
- 여러 보스 타입을 나누고 각 타입별 공격 패턴 구성
- 체력 50% 이하 등 조건에 따라 추가 패턴이 발생하도록 구현
- 플레이어 위치를 기준으로 폭발, 끌어당김, 레이저, 탄막 패턴 처리
- 바닥 타일 좌표를 기반으로 벽 생성, 파도형 벽, 플레이어 가두기 패턴 구현
- SoundManager에서 씬 로드 후 사운드 UI를 연결하고, SFX는 풀링 오디오 소스를 재사용하도록 구성
